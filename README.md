**Menu Mate** is an intuitive, responsive web application designed for residents of ITER Hostels (Institute of Technical Education and Research). It allows students to quickly check today's mess menu and preview tomorrow's meal schedule in advance.

---

## ✨ Features

- 📅 **Today & Tomorrow Menu Toggle**: Instant switching between today's menu and tomorrow's upcoming meals.
- 🏢 **Multi-Hostel Support**: Select between Girls Hostels (LH 1-4) and Boys Hostels (BH 1-12).
- 🥗 **Categorized Meal Cards**: Clean breakdown for Breakfast, Lunch, Evening Snacks, and Dinner.
- 🎨 **Modern Glassmorphic UI**: Vibrant gradient styling, responsive typography, and smooth meal card transitions.
- ⚡ **Offline & Cache Smart**: Automated daily interval checks and local storage caching for fast load times.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Modern CSS3 (Glassmorphism & Flexbox), Vanilla JavaScript (ES6 Modules)
- **Data**: JSON menu structures for today and tomorrow

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Vikashy05/Menu-Mate.git
   cd Menu-Mate
   ```

2. Launch `code/index.html` in any web browser, or serve locally:
   ```bash
   npx serve code
   ```
